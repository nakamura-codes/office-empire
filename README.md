# Office Empire — Contas locais de teste

Abra `index.html` no navegador. Clique em **Conta** para criar um usuário (3–20 caracteres) e uma senha de teste (mínimo 6 caracteres). Depois, entre e jogue normalmente. Cada usuário terá seu próprio progresso.

Tudo é salvo no `localStorage` do navegador. Não existe servidor, Firebase nem sincronização entre dispositivos. O GitHub Pages pode hospedar estes arquivos, mas não guarda os dados das contas.

**Atenção:** este é um sistema apenas para testes. As senhas de teste ficam armazenadas localmente sem proteção criptográfica; nunca reutilize uma senha real. Apagar os dados do navegador pode apagar todas as contas e os saves. Abrir o arquivo localmente e acessar o mesmo jogo pelo GitHub Pages também são armazenamentos diferentes.

Arquivos: `index.html`, `style.css`, `auth.js`, `game.js`.
